# Custom Explorer для Quartz

[English](README.md) · [Русский](README.ru.md)

Кастомизированный компонент дерева файлов и навигации для [Quartz](https://quartz.jzhao.xyz/). Репозиторий основан на Quartz Community Explorer и предназначен для сайтов, которым нужен привычный интерфейс проводника с возможностью задавать собственный порядок папок и заметок.

## Возможности

- Интерактивное дерево файлов и папок.
- Раскрытие и сворачивание папок.
- Кнопка мобильной навигации.
- Оформление проводника в стиле Quartz.
- Исключение каталога `tags` из дерева по умолчанию.
- Пользовательская сортировка через frontmatter Markdown:
  - `folderOrder` в файле `index.md` папки задаёт положение папки.
  - `noteOrder` в frontmatter заметки задаёт положение этой заметки.
- Алфавитная сортировка в качестве резервного варианта, если порядок не задан.

> **Важно:** значения для сортировки должны быть доступны проводнику во время выполнения. Если сборка Quartz исключает черновики или не передаёт поля frontmatter в индекс содержимого, для этих значений может потребоваться отдельный источник метаданных на этапе сборки.

## Требования

- Quartz 5 или новее (в метаданных плагина указано `quartzVersion: ">=5.0.0"`).
- Node.js 22 или новее и npm 10.9 или новее для локальной разработки и сборки.

## Установка

Выполните команду из каталога проекта Quartz:

```bash
npx quartz plugin add github:semsig13-tech/custom-explorer
```

Если плагин уже указан в конфигурации Quartz, убедитесь, что он включён и установлена версия, содержащая необходимые изменения.

## Подключение плагина

В `quartz.config.yaml` настройте плагин в списке компонентов/плагинов, используемом вашей сборкой Quartz. Для формата Quartz Community запись выглядит так:

```yaml
- source: github:semsig13-tech/custom-explorer
  enabled: true
  layout:
    position: left
    priority: 50
```

Если вы заменяете встроенный или другой community-проводник, отключите прежнюю запись Explorer, чтобы на странице не отображались два дерева навигации.

## Сортировка папок и заметок

Добавьте числовые значения порядка во frontmatter соответствующих Markdown-файлов.

### Порядок папок

Укажите `folderOrder` в файле `index.md`, который находится внутри папки:

```yaml
---
title: Функции защиты
folderOrder: 2
---
```

### Порядок заметок

Укажите `noteOrder` в frontmatter каждой заметки, для которой нужен заданный порядок:

```yaml
---
title: Основные защиты
noteOrder: 1
---
```

Чем меньше число, тем выше элемент в списке. Для элементов без заданного порядка применяется резервная сортировка, реализованная в плагине. Используйте числа, а не строки в кавычках (например, `noteOrder: 2`, а не `noteOrder: "2"`).

## Параметры конфигурации

Компонент поддерживает следующие параметры:

| Параметр | Тип | Описание |
|---|---|---|
| `title` | `string` | Заголовок над проводником. |
| `folderDefaultState` | `"collapsed" \| "open"` | Начальное состояние папок. |
| `folderClickBehavior` | `"collapse" \| "link"` | Сворачивать/раскрывать папку или переходить на её индексную страницу при нажатии. |
| `useSavedState` | `boolean` | Сохранять ли состояние папок в хранилище браузера. |
| `sortFn` | функция | Пользовательская функция сортировки элементов дерева. |
| `filterFn` | функция | Пользовательский фильтр элементов дерева. |
| `mapFn` | функция | Пользовательское преобразование элементов дерева. |
| `order` | массив | Порядок применения фильтрации, преобразования и сортировки. |

Пример переопределения параметров (для конфигураций Quartz, в которых параметры компонента задаются через TypeScript):

```ts
ExternalPlugin.Explorer({
  title: "Документация",
  folderDefaultState: "collapsed",
  folderClickBehavior: "link",
  useSavedState: true,
});
```

Используйте способ настройки, поддерживаемый установленной версией Quartz: расположение TypeScript-переопределений может различаться в разных проектах.

## Разработка

```bash
npm install
npm run build
```

Доступные проверки перечислены в `package.json`, в том числе `npm run typecheck`, `npm run lint`, `npm run format` и `npm test`.
