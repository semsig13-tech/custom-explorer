# Custom Explorer для Quartz

Плагин расширяет стандартный проводник Quartz: добавляет сортировку
заметок и папок по значениям YAML Frontmatter, сохраняет иерархическую
навигацию и поддерживает мобильное отображение.

## Возможности

-   Отдельная сортировка заметок и папок на каждом уровне дерева.
-   Сортировка заметок по `noteOrder`.
-   Сортировка папок по `folderOrder`.
-   Алфавитная сортировка внутри соответствующей группы, если поле
    порядка не задано или не содержит числовое значение.
-   Заметки всегда располагаются выше папок независимо от значений
    `noteOrder` и `folderOrder`.
-   Поддержка вложенных папок.
-   Исключение `index.md` из списка обычных заметок: файл используется
    как индекс и источник метаданных папки.
-   Папки с `index.md`, имеющим `draft: true`, остаются в проводнике;
    значение `folderOrder` при этом учитывается.
-   Мобильная навигация с раскрытием и сворачиванием панели.
-   Перенос длинных названий на мобильных экранах, чтобы текст не
    перекрывал область заметки.

## Как работает сортировка

Сортировка выполняется раздельно для заметок и папок:

1.  Сначала отображаются заметки.
2.  Заметки сортируются по возрастанию `noteOrder`.
3.  Затем отображаются папки.
4.  Папки сортируются по возрастанию `folderOrder`.
5.  Если у элемента нет корректного числового значения соответствующего
    поля, для него используется алфавитная сортировка по названию.

`noteOrder` сравнивается только с `noteOrder`, а `folderOrder` ---
только с `folderOrder`. Значения этих полей не сравниваются между собой.

### Пример: заметки

Добавьте `noteOrder` в YAML Frontmatter каждой заметки:

``` yaml
---
title: Подключение оборудования
noteOrder: 2
---
```

``` yaml
---
title: Общие сведения
noteOrder: 1
---
```

В проводнике «Общие сведения» будет выше «Подключение оборудования».

### Пример: папки

Порядок папки задаётся в Frontmatter её файла `index.md`:

``` yaml
---
title: Настройка оборудования
folderOrder: 2
draft: true
---
```

Для другой папки:

``` yaml
---
title: Введение
folderOrder: 1
draft: true
---
```

Папка «Введение» будет выше папки «Настройка оборудования».

> Важно: `folderOrder` указывается в `index.md` самой папки, а не в
> заметках внутри неё. Файл `index.md` не отображается как отдельная
> заметка. Папка остаётся доступной в проводнике, даже если её
> `index.md` помечен `draft: true`.

### Если порядок не задан

Если `noteOrder` или `folderOrder` отсутствует либо не является числом,
элемент сортируется по алфавиту внутри своей группы. Для предсказуемого
порядка рекомендуется задавать уникальные числовые значения там, где
требуется фиксированная последовательность.

## Установка

Плагин подключается как Quartz plugin из GitHub.

Добавьте источник в конфигурацию Quartz (`quartz.config.ts` или
соответствующий файл конфигурации вашей сборки --- в зависимости от
используемой версии/схемы проекта):

``` yaml
- source: github:semsig13-tech/custom-explorer
  enabled: true
  layout:
    position: left
    priority: 50
```

Если ваш проект использует другой формат регистрации плагинов,
перенесите эти параметры в соответствующую секцию конфигурации. После
изменения конфигурации выполните сборку Quartz.

## Генерация метаданных папок

Для сортировки папок используется карта `folder-order.json`, формируемая
emitter-плагином из `folderOrder` в Frontmatter файлов `index.md`.

Проверьте, что emitter `FolderOrderEmitter` подключён в цепочке emitters
Quartz и запускается при сборке сайта. В результате сборки должен
появляться файл:

``` text
public/static/folder-order.json
```

(Фактическая выходная директория может отличаться в зависимости от
конфигурации Quartz.)

Пример содержимого:

``` json
{
  "guides": 1,
  "guides/installation": 2,
  "reference": 3
}
```

Ключи --- slug папок относительно корня контента; значения --- числовые
`folderOrder`. Для вложенных папок используется полный относительный
путь через `/`.

Если карта не создаётся или значения отсутствуют, проверьте: - подключён
ли `FolderOrderEmitter`; - корректно ли указан `folderOrder` в
Frontmatter `index.md`; - является ли значение числом; - присутствует ли
`index.md` в исходной папке контента.

## Мобильное отображение

На узких экранах проводник открывается и закрывается с помощью
мобильного переключателя. Длинные названия папок и заметок переносятся
на несколько строк и остаются внутри области проводника, не перекрывая
основную область заметки.

## Сборка и проверка

После установки или обновления плагина:

1.  Запустите сборку сайта тем способом, который принят в вашем проекте
    Quartz.
2.  Убедитесь, что сборка завершилась успешно.
3.  Проверьте `static/folder-order.json` в выходной директории.
4.  Проверьте порядок заметок и папок на нескольких уровнях вложенности.
5.  Проверьте мобильную версию на узком экране.

Если сайт собирается через GitHub Actions, проверяйте результат в логе
соответствующего workflow и после публикации обновите страницу сайта.

## Примечание

Названия полей Frontmatter чувствительны к написанию: используйте именно
`noteOrder` и `folderOrder`. Поля должны находиться на верхнем уровне
YAML Frontmatter, а значения порядка должны быть числовыми.
