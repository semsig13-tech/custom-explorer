# Исправление сортировки folderOrder

## Что изменено

- Добавлен `FolderOrderEmitter`: на этапе сборки он использует `ctx.allFiles` и `ctx.allSlugs`, которые Quartz формирует до применения фильтров.
- Для каждого исходного `index.md` читает только числовое поле верхнего уровня `folderOrder`. Поле `draft: true` не мешает чтению метаданных; сама страница по-прежнему удаляется штатным `RemoveDrafts`.
- Генерируется `static/folder-order.json`, который загружается проводником.
- Заметки всегда выше папок на каждом уровне. Внутри каждой группы сортировка по `noteOrder`/`folderOrder`; элементы без порядка — по алфавиту.

## Установка

1. Обновить репозиторий `custom-explorer` этими файлами и выполнить `npm ci && npm run build`.
2. Закоммитить исходники и обновлённый `dist/` в GitHub.
3. В каждом Quartz-хранилище (`TDOC`, `TDOC-copy`, `TDOC-UG`) выполнить обновление плагинов по зафиксированному источнику, например `npx quartz plugin install --from-config`.
4. `quartz.config.yaml` менять не требуется: компонент и emitter входят в один пакет и активируются одной записью.

## Формат index.md

```yaml
---
draft: true
folderOrder: 2
---
```

`folderOrder` должен быть числом YAML, без кавычек.
